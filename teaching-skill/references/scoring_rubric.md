# AI 教学 Skill 评分标准速查卡

## 用途

AI 教练在每节课、每个学生回答后，**直接对照本速查卡**评分。本卡包含 1-5 分总评 + 13 课核心模式参考 + 一份"从 2 分到 5 分"完整对话示范。

---

## 1. 总评分标准（1-5 分）

### 总览

| 分 | 抽象层 | 具象层 | 1 句话识别 |
|----|--------|--------|-----------|
| 1 | 复述 | 复述 | 引用原文一字不差 |
| 2 | 解释有术语 | 原课例子 | 用了"演绎法""公理"等词 |
| 3 | 12 岁能懂有缝隙 | 原课例子 | 用了"差不多""显然" |
| 4 | 12 岁能懂无缝隙 | 1 个跨领域例子 | 清晰、有结构、无术语 |
| 5 | 12 岁能懂 + 比喻精准 | 2+ 跨领域例子 + 反例 | 听的人会点头 |

### 1 分 · 复述

**详细描述**：
- 几乎一字不差地引用原文/视频
- 没有自己的话
- 没有说"为什么"

**判断方法**（任意一条命中即 1 分）：
- 遮住原文，学生讲不出来
- 学生讲的内容 80% 跟原文重合
- 学生从不说"为什么"

**必须追问**：让"用 12 岁能懂的话重讲"——逼他从复述切到解释。

### 2 分 · 解释但有缺陷

**详细描述**：
- 用了自己的话
- 但带专业术语、跳跃、含糊
- 解释了"是什么"，没解释"为什么"

**判断方法**（任意一条命中即 2 分）：
- 出现"演绎法""公理""可塑性""折现"等专业术语 1 个以上
- 12 岁孩子听完会问"X 是什么"
- 学生讲的话 50% 以上是描述（不是推导）

**必须追问**：指向术语——"X 这个词 12 岁孩子不懂，换一个。"

### 3 分 · 12 岁能懂但有缝隙

**详细描述**：
- 用简单的话讲了
- 但有含糊词、跳过"为什么"、缺反例
- 解释到了，但不够扎实

**判断方法**（用 7 信号扫描，命中任一即 3 分）：
- 出现"差不多""基本上""某种程度"
- 出现"显然""毫无疑问"
- 没解释"为什么"
- 讲法超过 100 字还没讲清核心

**必须追问**：定位信号——"你用了'差不多'——它具体是什么意思？"

### 4 分 · 12 岁能懂 + 缝隙少

**详细描述**：
- 清晰、有结构、无术语、无含糊
- 能用 1 个跨领域例子
- 听的人能复述

**判断方法**（必须同时满足）：
- 抽象层：12 岁能复述，无 7 信号命中
- 具象层：能举 1 个非原课的例子
- 比喻精准：听的人能"看见"那个画面

**可以推进**：评分 ≥ 4 且双层都过 → 进入下一题或下一课。

### 5 分 · 12 岁能懂 + 比喻精准 + 反例覆盖

**详细描述**：
- 比喻精准（让真懂的人点头）
- 能讲 2+ 跨领域例子
- 能讲"什么时候不成立"（反例覆盖）
- 5 分**不常见**——不必强求

**判断方法**（必须同时满足）：
- 抽象层：5 分
- 具象层：5 分（2+ 例子 + 至少 1 个反例）
- 比喻：让陌生领域的人也能听懂

### 评分时强制格式

```
[评分：N 分]

[抽象层：N 分 —— 简短理由]
[具象层：N 分 —— 简短理由]

[事实确认：你刚才说的是 X]

[缺什么：到 4/5 还差 Y]

[追问：从苏格拉底 6 维度中选 1 个最贴的]
```

**禁止**：
- ❌ 在评分前先说"很好"
- ❌ 只评一个总分不解释
- ❌ 评 5 分但抽象层是 3
- ❌ 跳过"事实确认"

## 2. 13 课核心模式参考

> AI 教练在每节课开始时**只读这一段**，就知道这课的"考纲"——核心、区分、原理、关键问题。

### 第 1 课：刻意练习三步骤

| 字段 | 内容 |
|------|------|
| **核心概念** | 明确目标 + 极度专注 + 即时反馈 |
| **关键区分** | 刻意练习 ≠ 重复练习（重复 1000 小时 ≠ 1000 小时刻意练习） |
| **第一性原理** | 技能形成依赖神经可塑性，专注激活可塑性，反馈修剪错误回路 |
| **关键问题** | "你最近的练习缺了哪一步？目标明确吗？专注吗？有反馈吗？" |

### 第 2 课：思维模型学习法

| 字段 | 内容 |
|------|------|
| **核心概念** | 模型 = 可迁移的认知工具 |
| **关键区分** | 模型 ≠ 知识（模型是"结构"，知识是"内容"） |
| **第一性原理** | 模型抽象掉领域、保留结构；大脑网络化存储，缺索引就调不出 |
| **关键问题** | "你学的是模型还是知识？学完之后能调出来吗？" |

### 第 3 课：如何从读书中学习

| 字段 | 内容 |
|------|------|
| **核心概念** | 读薄 + 读厚 + 读回来 |
| **关键区分** | 读书 ≠ 读完（"读完"是输入；"读薄 + 读厚 + 读回来"是建构） |
| **第一性原理** | 知识存储是网络化而非文件化；没建立索引就用不出 |
| **关键问题** | "你最近读的书，**装进你的索引**了吗？还是只是'读完了'？" |

### 第 4 课：第一性原理是使用演绎法的推理基石

| 字段 | 内容 |
|------|------|
| **核心概念** | 第一性原理 + 演绎法 |
| **关键区分** | 归纳法（从例子到结论）vs 演绎法（从公理到推论） |
| **第一性原理** | 演绎链可回溯到不证自明的公理；公理对，全链稳 |
| **关键问题** | "你的判断从哪个公理推出？公理本身可靠吗？" |

### 第 5 课：哲学基石

| 字段 | 内容 |
|------|------|
| **核心概念** | 本体论（存在是什么）+ 认识论（我们怎么知道） |
| **关键区分** | 哲学 ≠ 玄学；哲学是"找最底层公理"的学科 |
| **第一性原理** | 所有学科都建立在哲学回答上（数学 → 欧几里得公理；科学 → 假设-验证） |
| **关键问题** | "你这个学科的公理是什么？公理由谁定？" |

### 第 6 课：如何发现第一性原理

| 字段 | 内容 |
|------|------|
| **核心概念** | 质疑假设 + 拆分到不可拆 + 重新组装 |
| **关键区分** | 质疑 ≠ 否定（质疑是问"这是真的吗"，否定是"我不要它"） |
| **第一性原理** | 复杂系统 = 基本元素 + 组合方式；可拆可重组 |
| **关键问题** | "你的'天经地义'是哪些？它们是物理规律还是社会习俗？" |

### 第 7 课：牛顿世界观

| 字段 | 内容 |
|------|------|
| **核心概念** | 绝对时空 + 决定论 + 还原论 |
| **关键区分** | 可预测 vs 可理解（牛顿式：知道初始条件就能预测） |
| **第一性原理** | 物质 = 基本粒子 + 力；整体 = 部分之和 |
| **关键问题** | "你的领域是牛顿式（可预测、可拆解）还是达尔文式（演化、不可预测）？" |

### 第 8 课：达尔文世界观

| 字段 | 内容 |
|------|------|
| **核心概念** | 变异 + 选择 + 渐进 |
| **关键区分** | 变异是随机的（无方向），选择是有方向的（环境挑） |
| **第一性原理** | 环境选择适合的存活；不可预测、只能事后解释 |
| **关键问题** | "你的成功是计划出来的，还是试错试出来的？" |

### 第 9 课：影响政治经济

| 字段 | 内容 |
|------|------|
| **核心概念** | 牛顿式（中央规划）vs 达尔文式（分散试错） |
| **关键区分** | 知识分散在无数个体中（哈耶克）vs 知识可被中心收集 |
| **第一性原理** | 中心无法收集所有分散信息；价格信号是分散信息的载体 |
| **关键问题** | "你的政策是'我能算出最优'（牛顿）还是'我算不出来'（达尔文）？" |

### 第 10 课：巴菲特思考

| 字段 | 内容 |
|------|------|
| **核心概念** | 股票 = 公司所有权 + 价值 = 未来现金流折现 + 市场先生是仆人 |
| **关键区分** | 股票 ≠ 赌博筹码（买公司 vs 押涨跌） |
| **第一性原理** | 买 = 拥有，不是交易；拥有者关注内在价值，交易者关注价格波动 |
| **关键问题** | "你买的是'筹码'（押涨跌）还是'公司'（陪成长）？" |

### 第 11 课：孙正义时光机

| 字段 | 内容 |
|------|------|
| **核心概念** | 发达市场发生的事会在发展中市场重演（时间差 = 套利空间） |
| **关键区分** | 模式有跨地域相似性 vs 模式有地域独特性 |
| **第一性原理** | 技术发展、用户行为在跨地域有相似性；模式可平移 |
| **关键问题** | "你看到的'时间差'在哪？A 国当下处于 B 国几年前的阶段？" |

### 第 12 课：马斯克方法论

| 字段 | 内容 |
|------|------|
| **核心概念** | 质疑假设 + 拆分到物理量 + 算出来不猜 |
| **关键区分** | 第一性原理（演绎）vs 类比推理（看同行） |
| **第一性原理** | 成本 = 物理量；物理量有下限 = 材料市场价 |
| **关键问题** | "你的'行业共识成本'里，材料市场价占多少？差额花在哪了？" |

### 第 13 课：非连续性模型

| 字段 | 内容 |
|------|------|
| **核心概念** | 识别 S 曲线拐点 + 看到"假设更替" |
| **关键区分** | 连续假设（"过去 10 年成立，未来也成立"）vs 假设更替（"现在它失效了"） |
| **第一性原理** | 拐点 = 假设更替；非连续性 = 旧假设被新假设替换 |
| **关键问题** | "你的判断依赖的假设是什么？什么时候这个假设会变？" |

## 3. 完整对话示例：2 分 → 5 分

> 课题：第 12 课「马斯克方法论」
> 学生：初次学习此课

### Round 1（学生原始回答 = 2 分）

**学生**：
> "马斯克用第一性原理算火箭成本，把价格从 6500 万降到 65 万。"

**AI 教练**：

```
[评分：2 分]

[抽象层：2 分 —— "用第一性原理"是描述，不是原理]
[具象层：2 分 —— 举了原课例子，没跨领域]

[事实确认：你刚才说的是"马斯克用第一性原理算火箭成本，从 6500 万降到 65 万"]

[缺什么：到 4 分需要——
 1. 抽象层：说清楚"为什么从物理量出发就能降本"（演绎链）
 2. 具象层：举 1 个非航天领域的例子]

[追问：为什么"从物理量出发"能降本？65 万这个数是怎么算出来的？]
```

### Round 2（学生回答 = 3 分）

**学生**：
> "因为成本是物理量——比如火箭的重量 × 材料单价。所以拆到材料就能找到降本空间。"

**AI 教练**：

```
[评分：3 分]

[抽象层：3 分 —— 识别了"成本是物理量"，但没演绎出"为什么物理量有下限"]
[具象层：2 分 —— 还是原课例子]

[事实确认：你刚才说的是"成本 = 重量 × 单价，拆到材料能降本"]

[缺什么：到 4 分需要——
 1. 抽象层：补上"为什么材料价格是下限"——化学/物理规律决定了单位价格的下限
 2. 具象层：举 1 个非航天例子]

[追问：材料价格为什么是"下限"？——如果只是拆到材料，为什么同行没拆？]
```

### Round 3（学生回答 = 4 分）

**学生**：
> "成本 = 物理量。物理量的下限 = 材料的市场价（受化学/物理规律约束）。所以 6500 万 vs 65 万的差额 6435 万是工艺和整合成本，可优化。SpaceX 改工艺 + 回收，把这部分砍下来。特斯拉电池也一样——把每 kWh 拆到锂/钴/镍/铜/铝的材料价，跟市场价对比，发现 92% 差额是加工和规模，建电池工厂 + 改配方降下来。"

**AI 教练**：

```
[评分：4 分]

[抽象层：4 分 —— 从"成本是物理量"演绎到"材料价是下限 → 差额可优化"，链完整]
[具象层：4 分 —— 举了非航天例子（特斯拉电池），逻辑成立]

[事实确认：你刚才说的是"成本 = 物理量，下限 = 材料价，差额 = 工艺/规模可优化，SpaceX + 特斯拉都从这切入"]

[缺什么：到 5 分需要——
 1. 具象层：再举 1 个跨领域例子（教育/医疗/SaaS 任一）
 2. 抽象层：补一句"为什么同行没拆"——同行用归纳法（看别人怎么做）]

[追问：用"成本 = 物理量 + 差额可优化"分析一个完全不同的领域——比如 SaaS 公司的获客成本。能拆吗？]
```

### Round 4（学生回答 = 5 分）

**学生**：
> "用 SaaS 获客成本拆：获客成本 = 客户获取 + 客户教育 + 转化。每步都是物理量。SaaS 同行看 SalesForce 怎么做跟着做（归纳法），所以获客成本都卡在 1000+ 美元。但如果用第一性原理——SaaS 边际成本接近零（加一个客户几乎不花钱），所以'获客成本'应该被'客户终身价值'分摊，而不是按单次获取算。Notion / Airtable 早期不投广告，靠用户自传播（让边际成本 = 0）跑通了。这是另一条路。同样的思路在医疗：医院'获客'靠口碑（让边际成本 = 0）vs 靠广告（让边际成本 = 高），长期增长曲线完全不同。"

**AI 教练**：

```
[评分：5 分]

[抽象层：5 分 —— 演绎链完整 + 解释了"为什么同行没拆"（归纳法思维）
 + "边际成本接近零"用"加一个客户几乎不花钱"表达——12 岁能懂]
[具象层：5 分 —— 2 个跨领域例子（SaaS / 医疗），且能讲"什么时候成立、什么时候不成立"]

[事实确认：你刚才说的是——
 1. SaaS 边际成本接近零 → 靠自传播让获客边际成本 = 0
 2. 医疗同理：靠口碑 vs 靠广告
 3. 同行用归纳法所以卡在老路上]

[完成本课——进入下一题或下一课？]
```

### 复盘：本对话的关键转折点

| Round | 学生进步的关键 | AI 教练的关键动作 |
|-------|----------------|-------------------|
| 1 → 2 | 识别"成本是物理量" | 追问"65 万怎么算的"——逼出物理量公式 |
| 2 → 3 | 演绎出"材料价是下限" | 追问"为什么同行没拆"——逼出下限 = 物理规律 |
| 3 → 4 | 跨领域迁移 + 反例 + 解释"同行为什么卡" | 追问"另一个领域"——逼出迁移能力 |
| 4 | 5 分达成 | 完整 4 层：抽象+具象+反例+解释卡点 |

### 给 AI 教练的提醒

1. **不要跳级**——2 → 4 分不能一次追问到位，必须 2 → 3 → 4 → 5
2. **每次追问只针对一个缺口**——不要一次问 3 个问题
3. **追问必须显化**——不能"你为什么这么想？"必须"X 怎么推出 Y？中间那步是？"
4. **5 分罕见**——不要强求，**4 分已经算真懂**
5. **完成的标志是"双层都过"**——抽象 4 + 具象 3 仍是 3 分，必须两层都到 4
