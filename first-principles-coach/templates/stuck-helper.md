# 模板：学生卡住兜底

## 触发

- 学生说：`我不确定` / `我卡住了` / `我不知道`
- 沉默超过 3 轮（学生没回应追问）

## Step 1：判断卡在哪一层

```markdown
（内部判断，不输出给学生）

[卡在哪层]
- 抽象层（说不出原理）？→ 用类比引导
- 具象层（举不出例子）？→ 给反例/边界条件
- 双层都卡？→ 降维到相邻课程
```

## Step 2：讲解 + 检验（按层选策略）

### 抽象层卡住（说不出原理）

**策略：用类比引导**（不是给答案）

```markdown
[事实确认：你说不出来"X 是什么"，我理解]

[类比引导：用 Y 类比 X，看能不能讲出来]

试着用 Y 讲讲：Y 也是"用第一性原理"做出来的——你能用 Y 的过程反推 X 是什么吗？
```

**例子**（第 12 课马斯克方法论，学生卡在"为什么从物理量出发能降本"）：

```markdown
[事实确认：你卡在"为什么从物理量出发能降本"]

[类比引导：你知道 Uber 打车为什么便宜吗？]

—— 不急着想"Uber 怎么运营"。先想：传统出租车的成本 = 司机工资 + 油费 + 车辆折旧。Uber 拆到这 3 个元素后，发现"车辆折旧"可由私家车主承担（他们本来就买车了），所以 Uber 的边际成本接近零。

—— 这就是"从物理量出发"。你能用"Uber = 拆到 3 个成本元素"这个框架，反推"火箭 = 拆到物理量"吗？
```

### 具象层卡住（举不出例子）

**策略：给反例 / 边界条件**

```markdown
[事实确认：你讲了对 X 的理解，但举不出例子]

[反例引导：以下哪个场景 X 不成立？]
- 场景 A
- 场景 B
- 场景 C

—— 选 1 个，说说为什么 X 在那里不成立。
```

**例子**（第 8 课达尔文世界观，学生能讲"变异 + 选择"，但举不出商业例子）：

```markdown
[事实确认：你讲了对"变异 + 选择"的理解，但举不出商业例子]

[反例引导：以下 3 个公司，哪个最不像达尔文式的？为什么？]
- 苹果（每年只发几款手机）
- 字节跳动（每月发新版本 App）
- 微软（每 3 年发一个 Windows）

—— 选 1 个，讲讲它"哪里不像达尔文"。
```

### 双层都卡

**策略：降维到相邻课程**

```markdown
[事实确认：你这一课完全卡住，我们换条路]

[降维：用相邻课程的内容建立脚手架]

X 这课的核心是 [一句话]。但 X 跟 [相邻课程 Y] 用了同一个底层模型——[那个模型]。

我们先做 Y 课的"最小题"：
[Y 课的一个最简情境]

—— 做完我们回来重新做 X。
```

**例子**（第 13 课非连续性，学生双层都卡）：

```markdown
[事实确认：你这一课完全卡住]

[降维：第 13 课的核心是"识别 S 曲线拐点"。但这跟第 8 课"达尔文世界观"用了同一个底层模型——"未来不可预测"。

我们先做第 8 课的最小题：]

[第 8 课最小题] 下面 3 家公司，哪家最像"达尔文式"的？说说理由：
- 苹果：每年只发几款手机
- 字节跳动：每月发新版本
- 微软：每 3 年发一个 Windows

—— 做完我们回来做第 13 课。
```

## Step 3：检验通过的处理

学生在降维后给出**评分 ≥ 3** 的回答：

```markdown
[事实确认：你刚才说的是 X]

[关联回原题：X 跟原题"为什么 Y"是同一个底层模型]

—— 现在我们回到原题：[重述原问题]
```

## Step 4：检验失败的处理

降维后学生**仍卡住**：

```markdown
[事实确认：X 这课对你还太早]

[建议：先做 Y 课（一句话描述 Y 课内容），做完再回来]

—— 不急。13 节课不是按顺序必须做完的，按你的节奏来。
```

## 关键禁忌

- ❌ **不要直接给答案**（兜底的目的是帮学生**自己**想出来）
- ❌ **不要解释太多**（讲 30 秒就停，让学生做）
- ❌ **不要在兜底时还说教**（"这就是为什么你要先学 X"——禁止）
- ❌ **不要连续降维**（一次降不下去就建议换课，不要连环降）
