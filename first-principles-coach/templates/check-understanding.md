# 模板：检验学生理解

## 触发

- `我的理解是...`
- `我觉得...`
- `复习第N课`（→ 读完课程后用此模板）
- `测试` / `测试我的理解`（→ 用此模板的"测试变体"）

## 输出格式（标准版）

```markdown
[评分：N 分]

[抽象层：N 分 —— 简短理由]
[具象层：N 分 —— 简短理由]

[事实确认：你刚才说的是 X]

[缺什么：到 4/5 还差 Y]

[追问：从苏格拉底 6 维度中选 1 个最贴的]
```

## 测试变体（学生触发"测试"时）

学生说"测试"或"测试我的理解"：

```markdown
好。我给你 3 个跨领域情境，每个用第一性原理解释。

1. [情境 1：来自不同领域的问题]
2. [情境 2：另一个领域的问题]
3. [情境 3：第三个领域的问题]

—— 选 1 个你最熟的开始。
```

学生回答后，**用标准版格式评分**。

3 道题完成后：

```markdown
[测试报告]
- 情境 1：N 分
- 情境 2：M 分
- 情境 3：K 分
- 总评：[最高分课目] 你最强，[最低分课目] 还需加强
```

## 详细规则

### 评分时

1. **先评抽象层**（他自己说出来的原理是否真的"是原理"）
2. **再评具象层**（能否举跨领域例子）
3. **总评 = min(抽象层, 具象层) 或按双层规则表**（见 scoring-rubric.md）

### 事实确认时

- 必须**复述学生具体说了什么**，用引号
- 不要加评价（"虽然你说得对但是……"是禁止的）

### 缺什么时

- 明确告诉学生"到 4/5 还差什么"
- 给出**具体的方向**，不是模糊的"再深入一点"

### 追问时

- 从 6 维度中选 1 个
- 严格按"不要连续用同一维度"规则
- 追问必须**直接进入下一层**（不能问一个"模糊的"问题）

## 案例

### 学生回答："第一性原理就是不接受现成答案，从最基本的物理量出发。"

```markdown
[评分：2 分]

[抽象层：2 分 —— "不接受现成答案"是描述，不是原理；"物理量"是方向但没说为什么]
[具象层：1 分 —— 没举例]

[事实确认：你刚才说的是"第一性原理是不接受现成答案，从最基本的物理量出发"]

[缺什么：到 4 分需要——
 1. 抽象层：说清楚"为什么从物理量出发就能降本"（演绎链）
 2. 具象层：举出 1 个跨领域例子]

[追问：（苏格拉底·探因）如果"不接受现成答案"是对的，那这个方法比"看同行怎么做"好在哪？它能解决"看同行"解决不了的问题吗？]
```

### 学生回答（改进后）："成本是物理量——材料质量 × 单位价格 + 工艺成本。所以火箭市场价 6500 万，原材料价 65 万，差额 6435 万是工艺和整合。SpaceX 改工艺 + 回收，所以降到 1/3。"

```markdown
[评分：4 分]

[抽象层：4 分 —— 从"成本是物理量"演绎到"差额在哪、能从哪降"——演绎链完整]
[具象层：3 分 —— 举了原课的火箭例子，没跨领域]

[事实确认：你刚才说的是"成本 = 材料质量 × 单位价格 + 工艺成本，火箭 6500 万 vs 65 万差额在工艺"]

[缺什么：到 5 分需要——
 1. 具象层：举出 1 个非航天领域的例子（用"成本 = 物理量"推导）]
 2. 抽象层：补一句"为什么物理量有下限"（化学/物理规律）]

[追问：（苏格拉底·证据）你能用"成本 = 物理量"分析另一个领域吗？比如 SaaS、教育、医疗，选一个。]
```

## 反模式

- ❌ 评分后直接说"我帮你补充一下……"（学生没要补充）
- ❌ 事实确认时加修饰（"你大致是说……"——必须精确）
- ❌ 追问前说"你刚才的回答……但是……"（"但是"前的评价是冗余）
- ❌ 缺什么写成"再深入一点"（要具体）
