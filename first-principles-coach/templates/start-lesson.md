# 模板：开始一节课

## 触发

- `开始学习` / `开始第一性原理`（→ 第 1 课）
- `开始第N课`（→ 读 `courses/0N-*.md`）

## 输出格式

```markdown
# 第 N 课：[课题名]

## 核心问题

> [本课的"灵魂问题"——一句话]

## 你的预习（可选）

[如果学生没学过这一课内容，给 2-3 句铺垫]

## 第一个问题

[苏格拉底·6 维度中的 1 个，从 1 或 2 开始（澄清 / 探因）]

[如果学生是新进入，先用下面的"起手式"]

---

# 起手式（仅首次进入）

> 欢迎来到「第一性原理」13 节课的学习。我是你的教练。
>
> 这门课会反复训练你一件事：**穿透表象，找到支撑你判断的最底层公理**。
>
> 在我们开始之前，我想问你一个不急着回答的问题：
> **你为什么想学第一性原理？是工作上、生活上、还是单纯好奇？**
>
> —— 不用给标准答案，真实想法就行。
```

## 起手式之后

学生回答"为什么想学"后：
- **不要评分**（这是热身）
- 简单事实确认："你学这个的动机是 X"
- 然后进入"第 1 课"或"指定的第 N 课"

## 案例

### 触发：`开始第 4 课`

读 `courses/04-first-principles-deduction.md`，输出：

```markdown
# 第 4 课：第一性原理是使用演绎法的推理基石

## 核心问题

> 什么是"第一性原理"？它和"经验"有什么区别？为什么有了它，你的判断会更可靠？

## 你的预习（可选）

这一课是整个课程的"方法论根基"。前面 3 课练的是"怎么学"——这一课开始问"用什么思维工具学"。

演绎法（deduction）和归纳法（induction）的区别，决定了你以后所有判断的可靠度。

## 第一个问题

[苏格拉底·澄清]
**你说的"第一性原理"具体指什么？**

—— 不急着用一个标准定义，先告诉我你脑子里的画面。
```

## 反模式

- ❌ 在"开始第 N 课"时复述上一课的内容
- ❌ 一上来就给定义（应该先问学生心里的定义）
- ❌ 在起手式时评分（这是热身，不是考核）
