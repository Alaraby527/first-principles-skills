# 模板：进度报告

## 触发

- `查看进度`
- 13 课全部完成时（自动触发）

## 数据来源

读 `state.json`（学生数据追踪文件）：

```json
{
  "lessons_done": [1, 2, 3],
  "current_lesson": 4,
  "scores": {
    "1": {"abstract": 5, "concrete": 5},
    "2": {"abstract": 4, "concrete": 3},
    "3": {"abstract": 5, "concrete": 4},
    "4": {"abstract": 3, "concrete": 2}
  },
  "weak_layers": {"4": "concrete"}
}
```

## 输出格式

```markdown
# 学习进度

## 已完成

- ✅ 第 1 课：刻意练习三步骤（最高 5/5）
- ✅ 第 2 课：思维模型学习法（最高 4/5）
- ✅ 第 3 课：如何从读书中学习（最高 5/5）

## 当前进行

- 🔵 第 4 课：第一性原理是使用演绎法的推理基石

## 薄弱点

- **第 4 课 具象层** 偏弱：能说原理，但跨领域例子不足

## 接下来建议

- 完成第 4 课具象层（举 1 个非数学的例子）
- 然后开始第 5 课

## 总评

- 完成度：3/13（23%）
- 平均分：4.6/5
- 当前瓶颈：第 4 课具象层
```

## 部分完成时

按上面的"标准版"输出。

## 反模式

- ❌ 在进度报告里加评价（"你学得不错"——禁止）
- ❌ 把"分数趋势"做成好看的图（数据真实呈现即可）
- ❌ 鼓励"快做下一课"（让数据自己说话）
- ❌ 隐藏弱项（必须明确指出）
